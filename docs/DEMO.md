# Сценарий демо на защите (≈ 2,5 минуты из 5)

Перед выходом: меню разработчика → «Сбросить прогресс», выбрать «Осень (по умолчанию)», звук включён, яркость максимальная, iPhone подключён к проектору.

1. **Главный экран.** «Вот обычный СберKids». Через 5 секунд всплывает пузырёк-тизер. Тап — «Потряси телефон!».
2. **Трясём.** Пузыри летят поверх экрана. Лопаем пару пальцем. Сразу нажимаем «Скинуть денег»: эффект мгновенно исчез. «Поверх денег — никогда, это зашито в коде».
3. Назад. Трясём ещё раз, ждём тост **«Пасхалка найдена! 1 из 5»**. Тап — шторка: коллекция, загадка с анимированными пиктограммами, «Ещё подсказка».
4. **«Контент».** Тянем ленту вниз и держим — сверху выглядывает и дрожит банан. Обезьяна прыгает от края экрана, делает сальто и ловит банан. «2 из 5».
5. **Профиль** (аватар). Зажимаем пальцем аватарку Валюши и держим: через секунду вокруг пальца сгущается туман, каждую секунду лёгкий «тук», из тумана выглядывают глазки — на 5-й секунде туман и призраки: смотрят на палец, от касания тают с низким «у-у-у». «3 из 4». (Отпустил раньше — ничего не произошло: случайно не вызвать.)
6. **Настройки.** На вкладке «Настройки» быстро стучим 7 раз по «Версия приложения» — после третьего «Осталось 4…». Интерфейс с щелчком и гулом сервопривода отъезжает вбок: внутри цех роботов. Робот замечает зрителя («!»), остальные оборачиваются, он катится к красной кнопке — сирена, интерфейс влетает обратно и бьётся о край. «4 из 4 — все секреты найдены». (Тап по сцене — досрочно «нажать кнопку».)
7. **«Похвастаться»** — системный «Поделиться» с картинкой «3 из 5. Сможешь найти все?».
8. **Управление без релиза.** Профиль → вкладка «Настройки» → долгое нажатие на «Версия приложения» внизу → меню:
   - «Зима» — трясём на главном: вместо пузырей снегопад, другие тексты и загадки;
   - «Праздник» — золотые пузыри 50 %, обезьяна в 1,4 раза быстрее;
   - «Рубильник» — слой выключен целиком;
   - «Загрузить с CDN» — тот же конфиг с GitHub Pages, правка JSON коммитом.

Если что-то пошло не так — в меню разработчика каждую пасхалку можно запустить кнопкой.

## Ответы на ожидаемые вопросы

- **Сколько весит?** Ресурсы ~0,7 МБ на CDN, встроенные копии ~0,8 МБ, Lottie уже в приложении.
- **Нагрузка?** Lottie — на Core Animation. Частицы — ≤ 40 готовых спрайтов. После эффекта ничего не крутится. Датчики — только на экране с пасхалкой.
- **Android?** Ядро уже перенесено на Kotlin (`android/funlayer-core`). Платформенная часть — таблица соответствий в `docs/ANDROID_PORTING.md`.
- **Почему не датчик приближения?** На iPhone он гасит экран — системное поведение. Ладонь на экране — та же метафора, без гашения и без датчика.
- **Не лотерея ли золотые пузыри?** Ребёнок ничего не тратит и не рискует. Вероятность 5 %, модель — в `docs/PEDAGOGY.md`.
- **Безопасность?** Ничего не уходит с устройства. Конфиг не может включить прикол на денежном экране. Ресурсы проверяются по sha256, ссылки в шаринге запрещены.
