# Педагогика, безопасность, модель вероятностей

## Почему механика устроена именно так

| Решение | На что опирается |
|---------|------------------|
| Цепочка «нашёл → загадка → следующий» | **Внутренняя мотивация** (теория самодетерминации Деси и Райана): автономия — ребёнок сам решает, искать ли; компетентность — сам разгадал; связанность — показывает друзьям. Нет внешних наград и давления. |
| Подсказка в два уровня: загадка → «Ещё подсказка» | **Зона ближайшего развития** (Выготский) и **scaffolding**: сначала даём подумать самому, помогаем ровно настолько, насколько попросили. |
| Пиктограммы до текста | Аудитория 6–13, младшие читают по слогам (ТЗ). Анимированная иконка жеста понятна без чтения. Тексты — короткие фразы, знакомые слова. |
| Первая пасхалка — от тряски на главном + тизер-пузырёк | Возрастная таблица из исследования: 6–7 лет — очевидный отклик и простое действие. Первый успех гарантирован. |
| Коллекция «1 из 5» со слотами | 8–10 лет — коллекционирование (та же таблица). Пустые слоты создают «эффект незавершённого действия» (Зейгарник) без принуждения. |
| Загадки, секретные места, разные жесты | 11–14 лет — исследование, секреты, «я знаю то, чего не знают другие». |
| Нет проигрыша, нет таймера, нет «попытки за…» | 6–7 лет — ошибка не наказывается; ТЗ — никаких тёмных паттернов, ложной срочности и обратного отсчёта. |
| Повторяемость: эффект вызывается снова, лопание пузырей, призраки исчезают от касания, редкий золотой вариант | Исследование: «возможность повторить — важная характеристика успешного контента»; критерий «прикол одноразовый» снижает баллы. |
| Смешное, животные, сюрприз | Исследование «Поколение Альфа»: 62 % — смешные клипы, 38 % — с животными, 78 % любят сюрпризы. |
| «Похвастаться» картинкой «3 из 5. Сможешь найти все?» | Контент — повод для социализации (исследование); виральность — 30 баллов. Без ссылок и QR. |
| Подсказки ведут по разделам «Контент», «Профиль»… | Ребёнок узнаёт функции приложения через игру — польза для продукта. Денежные экраны в цепочку не входят никогда. |

## Соответствие ограничениям ТЗ

| Требование | Как выполнено |
|------------|---------------|
| Не блокировать сценарии | отдельное окно, касания проходят насквозь; эффект ≤ 10 с |
| Не перекрывать оплату, перевод, реквизиты, лимиты | `ScreenPolicy.sensitive` в коде; при переходе эффект, тост и шторка гаснут мгновенно |
| Не замедлять запуск | на старте только чтение локального файла; сеть — через 2 с после главного |
| Без бэкенда | CMS-ключ + статика + локальное хранилище |
| Без новых разрешений и SDK | акселерометр, касания, Lottie — всё есть |
| Персональные данные не уходят с устройства | прогресс — только id пасхалок в UserDefaults; аналитики нет |
| Пустой/битый конфиг не ломает приложение | валидатор + встроенный конфиг; тесты |
| Без лотерей и ставок | ребёнок ничего не тратит и не рискует; модель вероятностей ниже |
| Без материальных наград | награда — эмоция и слот в коллекции |
| Без чужих брендов, IP, оружия | все персонажи и звуки нарисованы/синтезированы с нуля (`tools/`) |
| Без ссылок и QR | валидатор вырезает ссылки из текста шаринга |
| 0+/6+, без запугивания | призраки — добрые, с румянцем, хихикают; звук «ууу» мягкий; затемнение ≤ 35 % |
| Bluetooth для совместности | не нужен: виральность — через «покажи другу» и картинку |

## Модель вероятностей (случайные варианты)

Случайность — только косметическая: какой вариант эффекта покажется. Ребёнок ничего не тратит, ничем не рискует, на прогресс это не влияет. Выбор — `WeightedPicker`: вероятность варианта = вес / сумма весов.

| Конфиг | Пасхалка | Вариант | Вес | Вероятность |
|--------|----------|---------|-----|-------------|
| осень (по умолчанию) | Пузыри | радужные | 95 | 95 % |
| | | с золотыми пузырями | 5 | 5 % |
| праздник | Пузыри | радужные | 50 | 50 % |
| | | с золотыми пузырями | 50 | 50 % |
| все | Обезьяна, Призраки | единственный | 1 | 100 % |

Ожидаемое число запусков до первого золотого варианта при 5 %: 1 / 0,05 = 20; вероятность увидеть его хотя бы раз за 10 запусков: 1 − 0,95¹⁰ ≈ 40 %. Тест `weights` проверяет, что на 100 000 выборов доля золотых = 5 % ± 0,5 %.
